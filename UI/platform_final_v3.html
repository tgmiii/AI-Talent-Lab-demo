📖 基本用語辞典
print()
画面に値を出力する組み込み関数。デバッグや結果確認に最も多く使われます。
活用: print("こんにちは") → こんにちは と表示
" " (文字列)
ダブルクォーテーションで囲んだテキストデータ。シングルクォーテーション ' ' でも同じです。
活用: "Hello" → 文字列として扱われる
変数 (Variable)
データを保存する名前付きの箱。= で値を代入します。
活用: name = "AI" → name に "AI" を保存
def (関数定義)
繰り返し使うコードのまとまりに名前を付ける構文。
活用: def greet(): print("Hi") → greet() で呼び出し
# (コメント)
# 以降の行は実行されないメモ。コードの説明に使います。
活用: # ここは挨拶を表示する部分
( ) (括弧)
関数呼び出しに使う記号。引数（渡したい値）をこの中に書きます。
活用: print("値") → "値" が引数
💡 ラインヒント
全コードの各行にマウスを当てると
AIがその行の意味を一行で解説します
